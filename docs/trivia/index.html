How the two-phone game works

You both need to be on the same network.
  1. Any shared Wi-Fi works — home, café, hotel, or one phone's Personal Hotspot with the other joined to it.
  2. The network does not need internet access. Nothing is sent to a server. Your phones talk straight to each other.
  3. One of you hosts and shows a QR code. The other scans it, then shows a reply code back. That's the whole setup.
On a plane
  1. iPhone Personal Hotspot needs the cellular radio, so it can't be switched on in Airplane Mode. Android varies by model — some allow it, many don't.
  2. If the plane has Wi-Fi, both of you joining it usually works even without buying an internet pass. Some airlines block phone-to-phone traffic, in which case pairing will fail.
  3. If neither works, Play solo still runs with no network at all.
